# AMP Pattaya Static Prototype Page Map

## Public Website

- `index.html` - Homepage with hero, search, featured projects, proof, areas, trust, CTA and footer.
- `pages/buy.html` - Property sale listing with filters, sorting and property cards.
- `pages/rent.html` - Rental listing with compact filters and monthly pricing.
- `pages/projects.html` - New project listing with filters, project rows and static map.
- `pages/project-detail.html` - Project detail with gallery, facts, facilities, location, lead form and mobile sticky CTA.
- `pages/property-detail.html` - Property detail with gallery, specs, description, cost table, agent card and mobile sticky CTA.
- `pages/sell.html` - Seller landing page with valuation CTA, process and contact form.
- `pages/about.html` - Company trust, team and service positioning.
- `pages/contact.html` - Contact channel cards, lead form and map placeholder.
- `pages/shortlist.html` - Saved property layout with an empty-state card.
- `pages/compare.html` - Side-by-side project comparison table and recommendation block.
- `pages/buying-cost-estimator.html` - Static frontend calculator UI with isolated mock calculation.
- `pages/smart-finder.html` - Additional reference page for the 90-second buyer intake.
- `pages/area-guide.html` - Additional reference page for Pattaya area guide.
- `pages/foreign-ownership.html` - Additional reference page for the 49% foreign quota explainer.

## Admin / Back Office

- `admin/index.html` - Admin entry redirect/link to dashboard.
- `admin/login.html` - Static login card with AMP branding.
- `admin/dashboard.html` - KPI dashboard, funnel, lead source, recent leads, properties, tasks and activity.
- `admin/properties.html` - Property table, filters, status badges and edit links.
- `admin/property-form.html` - Static create/edit property form.
- `admin/projects.html` - Project table and filters.
- `admin/project-form.html` - Static create/edit project form.
- `admin/leads.html` - Lead kanban, lead table, source and status tags.
- `admin/lead-detail.html` - CRM-style lead detail, history, notes and follow-up task.
- `admin/users.html` - User table with role badges and status.
- `admin/settings.html` - Company, contact, website and lead-routing settings UI.

## Navigation Coverage

- Public header links to Home, Buy, Rent, Projects, Sell, About, Contact, Shortlist, Compare, Cost Estimator and Admin.
- Homepage additionally links to Smart Finder, Area Guide and Foreign Ownership via footer/content CTAs.
- Listing cards link to detail pages.
- Detail pages link back to listing pages and contact CTAs.
- Admin sidebar links to Dashboard, Properties, Add/Edit Property, Projects, Add/Edit Project, Leads, Lead Detail, Users, Settings and Back to Website.
