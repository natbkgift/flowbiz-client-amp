## Vision

AMP Pattaya is a **Real Estate Intelligence Platform** for the Pattaya region. It combines AI-powered property matching, multilingual content automation, and data-driven investment insights to serve buyers, renters, sellers, and investors across international markets.

The platform is not a listing aggregator. It is an **authority-first intelligence layer** that helps users make informed real estate decisions through curated data, smart tools, and expert advisory.

---

## Platform Type

**Intelligence Platform** -- not a marketplace, not a classifieds site.

Core differentiators:
- AI-powered Smart Finder (property matching by criteria)
- Investment calculator with ROI/yield projections
- Area intelligence guides (lifestyle, infrastructure, price trends)
- Developer profiles with project portfolios
- Multilingual content (TH, EN; future: CN, RU)

## Revenue Model

| Stream | Type | Rate |
|--------|------|------|
| Property Sales Commission | Transaction | 3--5% of sale price |
| Rental Management | Recurring | 1 month rent per year |
| Premium Listings | Service | 5,000--20,000 THB per listing |
| Sponsored Developer Profiles | Service | Tiered (silver/gold) |
| Marketplace Directory | Service | Featured placement fees |

---

## Primary Conversion Goal

**Lead Capture** -- every page on the platform should guide users toward a qualified inquiry:
- Inquiry form (property-specific or general)
- Smart Finder results to inquiry
- LINE OA conversation
- Direct contact (phone/email)

---

## Secondary Goals

1. Build SEO authority for "Pattaya real estate" keyword clusters
2. Establish content pillar pages as top-ranking resources
3. Create data moat through property database and area intelligence
4. Drive newsletter subscriptions for nurture sequences
5. Enable co-agent partnership pipeline

---

## Non-Goals (Out of Scope)

| Item | Reason |
|------|--------|
| Payment processing | Use external payment providers |
| Legal document generation | Requires legal review, out of platform scope |
| Full CRM system | Integrate with external CRM if needed |
| Native mobile app | Web-first; mobile responsiveness is sufficient |
| Property management software | Focus on lead generation and matching |
| User-generated listings | Platform-curated content only |
| Social media posting UI | Content automation runs as background service |
