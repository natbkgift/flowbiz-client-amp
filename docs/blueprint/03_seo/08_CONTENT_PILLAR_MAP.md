# 08 -- CONTENT PILLAR MAP

> Phase 3: SEO & Linking Layer -- Define content pillars, clusters, and supporting articles before writing any content.

---

## Content Strategy Overview

AMP Pattaya uses a **pillar-cluster model** to build topical authority. Each pillar page is a comprehensive guide that links to supporting cluster articles, which in turn link back to the pillar.

```
Pillar Page (high authority, broad topic)
  +-- Cluster Article 1 (specific subtopic)
  +-- Cluster Article 2 (specific subtopic)
  +-- Cluster Article 3 (specific subtopic)
  +-- Supporting Article (tangential, links to cluster)
```

## Content Priority

Focus on pillar pages + top 3 clusters per pillar:
- All 4 pillar pages
- 12 cluster articles (3 per pillar)

### Phase 2 (post-launch)

Complete remaining clusters and begin supporting articles:
- Remaining cluster articles
- Begin blog posts for long-tail keywords

---

## Content-to-Page Linking Rules

1. Every cluster article must link to its pillar page (in intro and conclusion)
2. Every pillar page must link to all its cluster articles
3. Cluster articles may cross-link to clusters in other pillars where relevant
4. Every guide should link to at least one project page and one area page
5. Blog posts link to relevant guides (supporting role)

---

## Keyword Tracking

Each cluster article tracks:
- Primary keyword
- Secondary keywords (2-3)
- Current ranking (update monthly)
- Target position
