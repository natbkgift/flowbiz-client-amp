# 15 -- CONTENT STANDARD

> Phase 5: Data Population Plan -- Guidelines for all written content on the platform.

---

## Tone & Voice

### Brand Voice

AMP Pattaya speaks as a **knowledgeable advisor** -- authoritative but approachable, data-driven but not cold.

| Attribute | Description |
|-----------|-------------|
| Authority | Speak from expertise, cite data, be specific |
| Clarity | Simple language, avoid jargon unless defined |
| Confidence | Direct statements, not hedging |
| Approachability | Professional but warm, not corporate |

### Language Register

| Context | Register | Example |
|---------|----------|---------|
| Headings | Direct, concise | "Jomtien Beach: Investment Hotspot" |
| Body copy | Informative, professional | "Average rental yields in this area range from 5-7% annually." |
| CTAs | Action-oriented | "Get your free property valuation" |
| Descriptions | Factual, appealing | "Fully furnished 2-bedroom condo with panoramic sea views" |

### Things to Avoid

- Superlatives without data ("the best", "most amazing")
- Pressure language ("don't miss out!", "limited time!")
- Vague claims ("great location", "excellent investment")
- First person ("we believe", "our team thinks")
- Passive voice where active is clearer

## SEO Content Structure

### H1-H3 Rules

| Level | Usage | Rules |
|-------|-------|-------|
| H1 | Page title | Exactly one per page. Contains primary keyword. |
| H2 | Major sections | 3-8 per page. Each should cover a distinct subtopic. |
| H3 | Subsections | Under H2s only. Use for lists, comparisons, details. |

**Never skip heading levels** (H1 -> H3 without H2).

### H1 Patterns by Page Type

| Page Type | H1 Pattern | Example |
|-----------|------------|---------|
| Property type landing | "{Type} for {Intent} in Pattaya" | "Condos for Sale in Pattaya" |
| Project page | "{Project Name}" | "The Riviera Jomtien" |
| Property detail | "{Title}" | "2BR Sea View Condo - Riviera Jomtien" |
| Area guide | "{Area} - Pattaya Area Guide" | "Jomtien - Pattaya Area Guide" |
| Developer page | "{Developer Name}" | "Heights Holdings" |
| Guide article | "{Guide Title}" | "How to Buy a Condo in Thailand as a Foreigner" |

### Meta Description

- Length: 150-160 characters
- Include primary keyword
- Include a value proposition or key fact
- End with a soft call-to-action when appropriate

Examples:
```
Project: "The Riviera Jomtien offers luxury beachfront condos from THB 3.5M. Sea views, pool, gym. Explore units and pricing."
Area: "Discover Jomtien Beach - Pattaya's family-friendly coastal area. Property prices, lifestyle guide, and investment data."
Guide: "Complete guide to buying property in Thailand as a foreigner. Legal requirements, ownership types, and step-by-step process."
```

## Image Optimization

### Format Requirements

| Context | Format | Max Size |
|---------|--------|----------|
| Hero images | WebP/AVIF (fallback JPG) | 200 KB |
| Gallery images | WebP/AVIF (fallback JPG) | 150 KB |
| Thumbnails | WebP/AVIF | 50 KB |
| Logos | SVG or PNG | 20 KB |
| Icons | SVG | 5 KB |

### Dimension Requirements

| Usage | Width | Aspect Ratio |
|-------|-------|-------------|
| Hero banner | 1920px | 16:9 or 3:1 |
| Project card thumbnail | 640px | 4:3 |
| Property gallery | 1200px | 4:3 |
| Team photo | 400px | 1:1 (square) |

### ALT Text Rules

Every image must have descriptive ALT text.

| Image Type | ALT Pattern | Example |
|------------|-------------|---------|
| Property exterior | "{Type} at {Project}, {Area}" | "2-bedroom condo at The Riviera, Jomtien" |
| Property interior | "{Room type} of {Type} at {Project}" | "Living room of 2BR condo at The Riviera" |
| Area hero | "{Area} aerial view / beach / skyline" | "Jomtien Beach aerial view" |
| Team photo | "{Name}, {Title}" | "Somchai P., Senior Property Advisor" |
| Developer logo | "{Developer} logo" | "Heights Holdings logo" |

### ALT Text Rules

- Describe what the image shows, not what it is for
- Include location or project name where relevant
- Keep under 125 characters
- Do not start with "Image of..." or "Photo of..."
- Do not stuff keywords

## Localization Standards

### English (EN)

- Use American English spelling (e.g., "color" not "colour")
- Currency format: THB 3,500,000 or 3.5M THB
- Date format: January 15, 2025
- Number format: 1,000,000

### Thai (TH)

- Use formal but readable Thai
- Currency format: 3,500,000 บาท or 3.5 ล้านบาท
- Date format: 15 มกราคม 2568 (Buddhist Era)
- Include Thai transliterations for location names where helpful

### Translation Rules

1. Translate meaning, not word-by-word
2. Keep proper nouns in English where that's the common usage (e.g., "Pool Villa" stays as is)
3. Developer names stay in English
4. Project names stay in English (with Thai transliteration if commonly used)
5. Area names: use common Thai names (จอมเทียน, พัทยา, etc.)
