## 5) Budget and Test Framework (Starter)

- Budget split for new condo lane:
  - 70% top 3 projects
  - 30% projects 4-7
- Ad set split:
  - 60% prospecting
  - 30% retargeting
  - 10% creative experiment
- Weekly keep/kill rule:
  - Keep: high qualified rate + stable CPQC
  - Kill: low quality 7 days consecutive

## 6) Quality Guardrails

- First response SLA <= 5 minutes (business hours)
- Keep auto-qualification <= 6 questions in first flow
- Ask for call only when user explicitly requests call
- Every inbound conversation must include tag minimum:
  - `locale`, `lead_type`, `offer_family`, `intent`, `campaign`, `call_requested`

## 7) Why these examples are likely to work

- Early-intent visual demand generation with short video formats
